Sensor DHT22

→ ESP32 3V3
DHT22 Pino 2 (DATA)
→ ESP32 GPIO 4
DHT22 Pino 3 (NC)
→ Não conectar
DHT22 Pino 4 (GND)
→ ESP32 GND
💡 Dica: Adicione resistor pull-up de 10kΩ entre DATA e VCC (opcional, mas recomendado para estabilidade).

⚠️ SEGURANÇA - IMPORTANTE!

Atenção com Alta Tensão (220V)

  • NUNCA trabalhe com o sistema ligado na tomada
  • Use relés com isolação óptica
  • Mantenha circuito de controle (5V) separado do circuito de potência (220V)
  • Use fios adequados para 220V (mínimo 1.5mm²)
  • Adicione fusível de proteção (10A)
  • Use caixa isolada para conexões 220V
  • Aterramento adequado é obrigatório
🚨 PERIGO DE CHOQUE ELÉTRICO

Circuitos de 220V podem causar lesões graves ou morte. Se não tem experiência com eletricidade, peça ajuda a um profissional!

📦 Montagem na Estufa

Vista Superior da Caixa:
┌───────────────────────────────────────┐
│  [DHT22]                      [LED]   │
│                                       │
│    ╔════════╗  ╔════════╗             │
│    ║ ROLO 1 ║  ║ ROLO 2 ║             │
│    ╚════════╝  ╚════════╝             │
│                                       │
│  [RESISTÊNCIA]        [VENTOINHA]     │
└───────────────────────────────────────┘

Posicionamento:
- DHT22: Centro, altura média
- Resistência: Base (lâmpada para cima)
- Ventoinha: Base (puxar ar de baixo)
- LEDs: Tampa transparente ou lateral
💡 Dica de Montagem:
  • Corte furos para fios e ventilação
  • Use suportes impressos em 3D para fixação
  • Mantenha circuito eletrônico isolado do calor
  • Adicione sílica gel no fundo da caixa
