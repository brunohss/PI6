🔧 Instalação do Software

Passo 1

Instalar Arduino IDE

Baixe e instale a versão mais recente do Arduino IDE (2.x recomendado).

💡 Link de Download: https://www.arduino.cc/en/software
Passo 2

Configurar ESP32 no Arduino IDE

  1. Abra Arduino IDE
  2. Vá em File → Preferences
  3. Em "Additional Board Manager URLs", adicione:
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  1. Clique OK
  2. Vá em Tools → Board → Boards Manager
  3. Busque por "ESP32"
  4. Instale "ESP32 by Espressif Systems"
Passo 3

Instalar Bibliotecas Necessárias

Vá em Sketch → Include Library → Manage Libraries e instale:

Biblioteca Versão Autor
DHT sensor library Última Adafruit
Adafruit Unified Sensor Última Adafruit
PID Última Brett Beauregard
Como instalar:
  1. Na busca, digite o nome da biblioteca
  2. Clique em "Install"
  3. Aguarde conclusão
  4. Repita para todas
Passo 4

Selecionar a Placa

  1. Conecte o ESP32 via USB
  2. Vá em Tools → Board → ESP32 Arduino
  3. Selecione ESP32 Dev Module (ou sua placa específica)
  4. Em Tools → Port, selecione a porta COM do ESP32:
    • Windows: COMx
    • Linux: /dev/ttyUSBx
    • Mac: /dev/cu.usbserial-xxxx

⚙️ Configuração Inicial

Editar Credenciais WiFi

Abra o arquivo estufa_filamentos.ino e localize estas linhas:

// ===== CONFIGURAÇÕES DE REDE =====
const char* ssid = "SUA_REDE_WIFI";           // Altere aqui
const char* password = "SUA_SENHA_WIFI";      // Altere aqui

Substitua por:

const char* ssid = "MinhaRedeWiFi";      // Nome da sua rede
const char* password = "minhaSenha123";   // Senha da sua rede
⚠️ IMPORTANTE: O ESP32 suporta apenas redes WiFi 2.4GHz. Redes 5GHz não funcionarão!

Verificar Pinos (Opcional)

Se estiver usando pinos diferentes, edite:

// ===== PINOS =====
#define DHTPIN 4              // Pino do DHT22
#define RELE_RESISTENCIA 5    // Relé da resistência
#define RELE_VENTOINHA 18     // Relé da ventoinha
#define LED_WIFI 2            // LED WiFi
#define LED_RESISTENCIA 15    // LED Resistência
#define LED_VENTOINHA 19      // LED Ventoinha

📤 Upload do Código

Processo de Upload

  1. Conecte o ESP32 via USB
  2. Abra o arquivo estufa_filamentos.ino
  3. Verifique se a placa e porta estão corretas em Tools
  4. Clique em Upload (seta para direita) ou Ctrl+U
  5. Aguarde compilação e upload
Se der erro "Failed to connect":
  • Segure o botão BOOT no ESP32
  • Clique em Upload novamente
  • Solte o botão quando começar a gravar

Monitorar Serial

Após upload bem-sucedido:

  1. Abra Tools → Serial Monitor
  2. Configure velocidade para 115200 baud
  3. Você verá:
=== ESTUFA PARA FILAMENTOS ===
Conectando WiFi.........
WiFi Conectado!
IP: 192.168.1.100
Servidor web iniciado!
⚠️ IMPORTANTE: Anote o endereço IP mostrado! Você precisará dele para acessar a interface web.

🚀 Primeiro Uso

Acesso ao Painel Web

  1. Certifique-se que seu computador/celular está na mesma rede WiFi
  2. Abra um navegador (Chrome, Firefox, Safari)
  3. Digite na barra de endereços: http://192.168.1.100
    (Use o IP mostrado no Serial Monitor)
  4. A interface web deve carregar!
Interface Web - Visão Geral

A interface mostra:

  • 📊 Cards com Temperatura, Umidade, Setpoint e Validade
  • 🎛️ Seletor de Material (PLA, PETG, ABS, Nylon, TPU)
  • ⚙️ Controles: Ligar/Desligar Sistema, Resetar Validade
  • 🔥 Botões de Modo: Secagem e Armazenamento
  • 💡 Indicadores: Resistência e Ventoinha

📖 Manual de Operação

Como Secar um Filamento Novo

Cenário: Você comprou um rolo novo de PLA que precisa ser seco.

1

Ligue o sistema clicando em "Ligar Sistema". O LED WiFi deve estar aceso.

2

No dropdown "Material Selecionado", escolha PLA. O sistema ajusta temperatura automaticamente.

3

Clique no botão "🔥 Secagem". Sistema aquece para 50°C e timer inicia (5h para PLA).

4

Monitore o processo. A temperatura deve subir até ~50°C, resistência ligará/desligará automaticamente, e ventoinha permanece ligada.

5

Após 5 horas, sistema automaticamente muda para "Armazenamento", reduz temperatura para 28°C e reseta validade para 730 dias.

Como Armazenar Filamento

Cenário: Filamento já está seco e você quer mantê-lo assim.

  1. Ligue o sistema
  2. Selecione o material (ex: PETG)
  3. Clique em "📦 Armazenamento"
  4. Sistema mantém temperatura 30°C, umidade <15% e contador de validade ativo

🔍 Troubleshooting

ESP32 não conecta WiFi

Sintomas:

Serial Monitor mostra "Conectando WiFi........" infinitamente. LED WiFi não acende.

Soluções:
  1. Verifique SSID e senha no código
  2. Certifique-se que WiFi é 2.4GHz (ESP32 não suporta 5GHz)
  3. Aproxime ESP32 do roteador
  4. Reinicie ESP32 (botão RST ou desconectar USB)
  5. Teste com hotspot do celular

DHT22 mostra "--" ou NaN

Sintomas:

Temperatura/umidade aparecem como "--". Serial Monitor mostra "Erro ao ler DHT22!"

Soluções:
  1. Verifique conexões do DHT22 (VCC, DATA, GND)
  2. Adicione resistor pull-up 10kΩ entre DATA e VCC
  3. Troque DHT22 (pode estar defeituoso)
  4. Use cabo mais curto (<50cm)
  5. Teste com código exemplo: File → Examples → DHT sensor library → DHTtester

Relés não acionam

Sintomas:

Não ouve "click" dos relés. Resistência/ventoinha não ligam.

Soluções:
  1. Verifique se relé está recebendo 5V (VCC/GND)
  2. Teste invertendo lógica (alguns relés são ativos em LOW)
  3. Verifique se GPIO escolhido suporta output
  4. Teste manual via código temporário

Temperatura não estabiliza

Sintomas:

Temperatura oscila muito (±5°C). Nunca alcança setpoint.

Soluções:
  1. Ajustar PID: Aumente Ki, aumente Kd, reduza Kp
  2. Melhorar isolamento da caixa
  3. Reduzir potência da resistência
  4. Adicionar massa térmica (água em garrafa)

✅ Checklist de Verificação

Antes de ligar pela primeira vez:

  • Conferir todas as conexões contra o diagrama
  • Verificar polaridade de LEDs (+/-)
  • Testar isolamento do circuito 220V
  • Confirmar relés com carga pequena
  • WiFi configurado corretamente
  • Serial Monitor funcionando (115200 baud)
  • IP anotado
  • Página web carrega
  • DHT22 lê temperatura ambiente
  • Todos os LEDs acendem no teste
  • Backup do código feito
🎉 Parabéns!

Se todos os itens estão verificados, você está pronto para usar sua estufa inteligente!
